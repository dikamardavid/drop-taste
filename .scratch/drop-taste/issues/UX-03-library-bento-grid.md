# UX-03 — Web Dashboard: Taste Library Gallery & Bento Grid

**What to build:**
Desain halaman utama Taste Library pada web dashboard Drop Taste. Menampilkan navigasi atas, filter bar interaktif (pencarian teks, filter kategori, dan tab pills: *All Items*, *📄 Pages*, *🧩 Components*, *🖼️ Image References*), serta galeri bento card responsif yang menampilkan thumbnail visual, badge tipe berwarna, judul, domain asal, kategori, dan tag chips.

**Blocked by:** UX-01 — Design System & Design Tokens Foundation.

**Status:** ready-for-agent

- [ ] Header & Navigation Bar dengan branding Drop Taste, tab navigasi (*Taste Library*, *Connect MCP*, *Profile*).
- [ ] Filter bar dengan input pencarian, dropdown filter kategori, dan pills filter tipe aset.
- [ ] Kartu bento reference dengan layout preview visual di atas dan metadata deskripsi di bawah.
- [ ] State handling: Default, hover elevation, loading skeleton, dan empty state ramah pengguna.
