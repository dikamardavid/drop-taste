# UX-01 — Design System & Design Tokens Foundation

**What to build:**
Fondasi visual design system lengkap untuk seluruh ekosistem Drop Taste (Chrome Extension, Web Dashboard, dan Figma Plugin). Menyediakan palet warna dark mode bento, skala tipografi display hingga mono, spacing geometris terukur (4/8/12/16/24/48px), radius kurva (6px, 10px, 14px, 9999px), serta komponen atomik baku (buttons, input fields, badges, tabs, card containers, dialog modals).

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Koleksi variabel Figma (Tokens) untuk Color (Canvas, Surface, Elevated, Borders, Accent Glow, Success, Danger).
- [ ] Skala tipografi lengkap dengan hierarchy role (Display Hero, Section H1/H2, Body, Caption, Monospace).
- [ ] Spacing dan corner radius scale terdefinisi dalam Figma Variables.
- [ ] Komponen atomik utama (Button primer, sekunder, danger, pill badges, input, dropdown select, modal container) siap pakai dengan auto-layout.
