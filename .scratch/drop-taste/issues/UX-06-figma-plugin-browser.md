# UX-06 — Figma Plugin UI: Library Browser & Auto-Layout Inserter

**What to build:**
Desain antarmuka panel plugin Figma Drop Taste dengan dimensi standar 360 × 560px. Memungkinkan desainer melihat status akun yang terautentikasi, mencari dan memfilter referensi dari cloud library, melihat kartu referensi dalam format ringkas dengan drag handle, serta menekan tombol aksi *"Insert to Canvas"* untuk menempatkan komponen ke dalam canvas Figma.

**Blocked by:** UX-01 — Design System & Design Tokens Foundation.

**Status:** ready-for-agent

- [ ] Frame panel plugin 360 × 560px dengan layout header profil pengguna dan status koneksi cloud library.
- [ ] Input pencarian dan tab filter kategori/tipe yang dioptimalkan untuk ruang ringkas.
- [ ] Desain kartu referensi padat (compact cards) dengan thumbnail, judul, pill tipe, dan visual drag handle.
- [ ] Micro-interactions: Feedback visual saat item di-drag atau saat tombol insert ditekan.
