# UX: Web — Public Landing Page

**What to build:**
Desain antarmuka Landing Page publik untuk Drop Taste dengan fokus konversi tinggi dan branding premium:
- **Top Bar:** Brand logo DT, link navigasi Overview / Library / Connect, serta tombol [Sign In] & [Sign Up].
- **Hero Section:** Headline utama ("Curate Web Taste into Figma & AI Coding Agents"), value proposition, visual mockup 3 pilar capture, tombol primer CTA "Download Chrome Extension", dan tombol sekunder "Explore Taste Library ↗".
- **How It Works (3 Langkah Sederhana):**
  1. Capture from Web (Hover inspector & page scanner).
  2. Cloud AI Synthesis (Auto layout AST & design.md).
  3. Figma & Agent Paste (Cmd+V di canvas atau prompt ke Claude/Cursor via MCP).
- **Pricing Section:**
  - Starter Free ($0/mo): 50 capture/bulan, Full Page & Component, Copy to Figma, MCP server access.
  - Pro Designer ($19/mo): Unlimited capture, unlimited Vision AI synthesis, multi-reference blending, priority bandwidth.
- **Call to Action (CTA) Download Extension:** Banner penutup di bagian bawah halaman mengajak instalasi ekstensi Chrome.
