# 04 — Web Dashboard: Library, Detail Page, Profile, Connect & Agent Token Management

**What to build:**
A responsive Web Dashboard providing Home, Library, Detail, Profile, and Connect views. The Library allows filtering by category, tags, and capture type. The Detail view presents full design traits, previews, and a 1-click "Copy to Figma" button writing native Figma clipboard data. The Connect view offers step-by-step setup guides for Claude, Antigravity, and custom runtimes, displaying connected agent audit logs and instant 1-click token revocation.
